# QA scripts

- `capture-reference.mjs`: capture reference routes and structured audit data.
- `reference-text.mjs`: capture loaded reference homepage and print page text.
- `site-qa.mjs`: check local routes, screenshots, overflow, and accessibility.
- `responsive-check.mjs`: inspect homepage across target viewport widths.
- `contact-visual.mjs`: capture contact page at selected viewport widths.
- `map-check.mjs`: inspect contact map loading and failures.
- `dev-site-check.mjs`: smoke-test deployed development contact page.
- `debug-accessibility.mjs`: inspect mobile overflow and axe violations.
- `width-check.mjs`: list elements with largest rendered widths.

Run scripts from repository root so artifact output paths resolve correctly.
