# UTERO Legal rebuild

Planning workspace for rebuilding https://legal.uteroindonesia.com/ with React, TypeScript, Vite, Tailwind and React Router. **Documentation describes planned work, not completed implementation.** Current UI remains Vite starter; `npm run build` does not prerender routes.

Local start: `npm ci`, `npm run dev`. Existing Docker/Nginx are scaffolding; read `docs/DEPLOYMENT.md` before deployment. No public deployment verified.

Project documents: `docs/PRD.md`, `docs/DESIGN_SYSTEM.md`, `docs/REFERENCE_AUDIT.md`, `docs/CONTENT_AUDIT.md`, `docs/ARCHITECTURE.md`, `docs/IMPLEMENTATION_PLAN.md`, `docs/PAGE_INVENTORY.md`, `docs/ASSET_MANIFEST.md`, `docs/TEST_PLAN.md`. Existing `docs/SECURITY.md` and `docs/DEPLOYMENT.md` describe infrastructure constraints. Research snapshots live in `artifacts/reference/`; local QA captures and comparisons live in `artifacts/qa/`. These files are not deployable assets.
